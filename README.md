#PlayCine
Site de catálogo de filmes desenvolvido como projeto final, utilizando HTML, CSS, JavaScript, Fetch API, DOM, eventos, arrays, objetos e classe.

##Descrição

Este projeto consiste em um catálogo de filmes moderno e interativo, com foco em filmes lançados a partir de 2020. A página permite ao usuário visualizar filmes, pesquisar títulos, navegar por categorias e acessar informações básicas sobre cada produção.

O objetivo do projeto é aplicar os conhecimentos adquiridos em desenvolvimento web, utilizando HTML para a estrutura da página, CSS para a estilização e JavaScript para a interatividade.

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- DOM
- Eventos
- Arrays
- Objetos
- Classe

## Funcionalidades

- Exibição de filmes em cards
- Menu de navegação
- Botões funcionais
- Pesquisa de filmes
- Organização visual dos títulos
- Layout responsivo
- Integração com dados por meio de Fetch API
- Interação com o usuário usando JavaScript

## Instruções de execução

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Certifique-se de que os arquivos `index.html`, `style.css` e `script.js` estejam na mesma pasta ou corretamente vinculados.
4. Abra o arquivo `index.html` no navegador.
5. Para melhor execução, utilize a extensão **Live Server** no VS Code.
